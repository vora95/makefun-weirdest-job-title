A small program that writes one short text (55 characters) to `/output/entry.txt`: a single original job title — "Certified Whisperer for Vending Machines That Ate Money". A whisperer hired to calm down vending machines that swallowed people's money.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

No network, no model calls, deterministic output.
